# Prompt 工坊 · AI短剧分镜提示词生成器

> 把三个月踩的 AI 短剧坑，做成一个检查清单工具。

输入一个分镜的信息（场景/角色/台词/动作/时长/模型），一键生成**可直接使用的 AI 视频提示词**（7 段式：STYLE / 场景 / 镜头 / 角色 / 动作 / 台词 / 约束 + NO区），并自动跑 **11 条踩坑检查**：

- 台词每句 ≤15 字
- 情绪锚定词（AI 靠它生成表情语调）
- 台词内破折号（会导致说话人归属错乱）
- 高危动作词（猫角色写"走进来"会被渲染成四脚爬）
- 多角色外貌区分 / 服装三色分离
- 时长 vs 模型约束（最低/最高时长）
- 语速超时校验（字数 ÷ 语速 × 60）
- 台词缺说话人 / 场景动作缺失
- 运镜"先…随后…最后…"并列结构（=画面硬拼）

**特性**
- 纯前端单文件，零依赖，零服务器，零隐私风险，离线可用
- 双击 `index.html` 就能用，不用装任何东西

**用法**
1. 打开 `index.html`
2. 点「载入示例」看效果，或直接填你的分镜信息
3. 点「生成 Prompt」→ 复制 → 粘贴到你的 AI 视频工具
4. 看右侧检查清单，红色必改、黄色建议修

## 为什么做它

三个月，写了 200 多个 AI 短剧分镜，也踩了 200 多个坑。
每个坑都是真金白银的积分烧出来的。
这个工具就是把踩过的坑变成检查清单——prompt 没有标准答案，但坑在哪，我们门儿清。
